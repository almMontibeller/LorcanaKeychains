# Whispers in the Well v08

Open [Set_10_Whispers_in_the_Well_v08.3mf](Set_10_Whispers_in_the_Well_v08.3mf) as a Bambu Studio project.

Bambu Lab A1, 0.4 mm nozzle, 0.20 mm layers, Arachne with 3 wall loops, 5 top and 5 bottom layers, 15% grid infill, Textured PEI, supports off, no brim, and prime tower enabled. The filament profiles and colour assignments are those of the original v07 build.

The [v07 artwork](../v07/README.md), geometry, plate placement, and filament slot assignments carry over. The [v07 project with its saved settings](../v07/Set_10_Whispers_in_the_Well_v07.3mf) is available for comparison.

The existing toolpath audit passes for the connected backing, lettering, and open letter counters. The v07 Classic profile fell below the coverage threshold on the first S at the first relief layer. Bambu Studio 02.09.01.70 sliced v08 with all 3 colours and no plate warnings. The v08 validation covers geometry preservation and slicer output. A physical print has yet to be recorded.
