# Fabled v1.7

Open [Set_09_Fabled_v1.7.3mf](Set_09_Fabled_v1.7.3mf) as a Bambu Studio project.

Bambu Lab A1, 0.4 mm nozzle, 0.20 mm layers, Arachne with 3 wall loops, 5 top and 5 bottom layers, 15% grid infill, Textured PEI, supports off, no brim, and prime tower enabled. The filament profiles and colour assignments are those of the original v1.6 build.

The [v1.6 artwork](../v1.6_approved/README.md), geometry, plate placement, and filament slot assignments carry over. The [v1.6 project with its saved settings](../v1.6_approved/Set_09_Fabled_v1.6.3mf) is available for comparison.

Both profiles passed the existing toolpath audit. The Arachne profile matches the collection and retains the complete lettering, ornament, and book-opening toolpaths. Bambu Studio 02.09.01.70 sliced v1.7 with all 3 colours and no plate warnings. The v1.7 validation covers geometry preservation and slicer output. A physical print has yet to be recorded.
