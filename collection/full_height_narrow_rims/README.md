# Full-height loops with narrower radial rims

All fourteen current projects have loops level with the **2 mm backing**. The ring is narrower in the XY plane: **10.5 mm nominal outer diameter**, **6.5 mm hole**, and **2 mm nominal radial rim**. The hole centre and all non-bore backing contours are retained.

All fourteen projects pass Bambu slicing with every intended filament and no plate warnings. Mesh checks confirm uniform 2 mm height across the complete backing, and actual toolpaths confirm the loop top at Z=2 mm. Colour meshes and profiles are preserved, including Set 05’s continuous 0.9 mm underline and reinforced stars. All five underline layers remain continuous with zero detached deposits. The unchanged Set 14 Caramel mesh retains its four pre-existing degenerate faces; all rebuilt backings have none. Physical printing and chain fit have not been tested.
