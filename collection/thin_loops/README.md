# Thin attachment loops and continuous Set 05 underline

All fourteen current projects have flat **1.6 mm attachment loops** joining their **2 mm backing** at a vertical step, retaining the 5.5 mm holes and nominal 10.5 mm outer diameter. The junction position adapts to keep artwork fully supported. Set 05 also has a smooth **0.9 mm ivory underline** with rounded ends.

All fourteen projects pass Bambu slicing, use all intended colours, and report no plate warnings. Actual toolpaths confirm that every loop ends at 1.6 mm. Set 05’s underline is continuous without detached deposits in all five ivory layers. Source projects, colour profiles and backing footprints are preserved. The source Set 14 Caramel mesh retains its four existing degenerate faces; all rebuilt backings have none. No physical print or chain-fit test was performed.
